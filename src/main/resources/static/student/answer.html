答题说明

1. 先在“签到”页面签到，签到页会把课堂 ID 存到浏览器里。
2. 点“加载题目”从后端拿老师发布的题目。
3. 每个选项只能选一个，提交后不能重复提交同一道题。

M4 负责这个页面：
1. 后端写 GET /api/exercise/list?classroomId=1（可以和 M2 商量）和 POST /api/answer，答题实体放 entity/Answer.java。
2. 前端 loadExercise() 拿到题目后，把 options 用 split('|') 拆成 4 个选项显示出来。
3. submitAnswer() 调答题接口，参数是 { exerciseId, studentId: user.userId, chooseOption: 'A' }， 返回的 correct 决定提示“答对了”还是“答错了”。
