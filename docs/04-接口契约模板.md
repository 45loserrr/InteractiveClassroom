# 接口契约模板

> **接口先行，契约是圣旨。**
> 任何前端页面开工前，接口必须先在本文件定稿；任何一方要改字段，必须先改本文件并通知全员，否则视为无效变更。

---

## 0. 通用约定

### 0.1 基础信息

| 项 | 值 |
| :--- | :--- |
| Base URL（本地） | `http://localhost:8080` |
| 接口前缀 | `/api` |
| 数据格式 | `application/json; charset=utf-8` |
| 鉴权方式 | `Authorization: Bearer <token>` |
| 在线文档 | `http://localhost:8080/swagger-ui.html` |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（东八区） |
| 字符集 | UTF-8（数据库 `utf8mb4`） |

### 0.2 统一响应体（所有接口必须遵守）

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | int | 0 成功；非 0 为业务错误码 |
| `message` | string | 给人看的提示，前端可直接 toast |
| `data` | object/array/null | 业务数据，失败时为 `null` |

### 0.3 业务错误码

| code | 含义 | HTTP |
| :--- | :--- | :--- |
| 0 | 成功 | 200 |
| 401 | 未登录 / Token 失效 | 401 |
| 403 | 无权限（如学生调教师接口） | 403 |
| 1001 | 课堂码不存在 | 200 |
| 1002 | 课堂已结束 | 200 |
| 1003 | 重复签到 | 200 |
| 2001 | 已提交过答案 | 200 |
| 2002 | 题目未发布 / 已截止 | 200 |
| 3001 | 抢答未开始或已结束 | 200 |
| 3002 | 重复抢答 | 200 |
| 500 | 服务器内部错误 | 500 |

## 1. 登录

### 1.1 教师登录

```
POST /api/auth/login
Content-Type: application/json
```

**请求**

```json
{
  "username": "teacher01",
  "password": "******"
}
```

| 字段 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| username | string | 是 | 教师账号 |
| password | string | 是 | 密码（后端 BCrypt 校验，禁止明文存储） |

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9....",
    "userId": 1,
    "username": "teacher01",
    "realName": "王老师",
    "role": "teacher",
    "expireAt": "2026-01-01 12:00:00"
  }
}
```

### 1.2 学生进入课堂（免注册）

```
POST /api/auth/student-join
```

```json
{
  "studentNo": "2023001",
  "realName": "张三",
  "classCode": "888888"
}
```

**响应**：同教师登录结构，`role` 为 `student`，附带 `classroomId`。

## 2. 课堂

### 2.1 创建课堂

```
POST /api/classroom
Authorization: Bearer <teacherToken>
```

```json
{
  "name": "软件工程导论-第3次课",
  "className": "计科2301",
  "expectedCount": 45
}
```

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "classroomId": 12,
    "name": "软件工程导论-第3次课",
    "classCode": "888888",
    "status": "ongoing",
    "createdAt": "2026-01-01 09:00:00"
  }
}
```

**规则**：`classCode` 6 位数字，全局唯一；同一教师同一时间只允许 1 个 `ongoing` 课堂。

### 2.2 结束课堂

```
PUT /api/classroom/{classroomId}/close
```

**响应**：`data` 返回 `{"status":"closed"}`。

### 2.3 课堂实时概览（大屏轮询兜底）

```
GET /api/classroom/{classroomId}/overview
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "expectedCount": 45,
    "checkedInCount": 38,
    "checkinRate": 0.844,
    "currentExerciseId": 33
  }
}
```

## 3. 签到

### 3.1 学生签到

```
POST /api/checkin
Authorization: Bearer <studentToken>
```

```json
{
  "classroomId": 12,
  "studentId": 101
}
```

**响应**

```json
{
  "code": 0,
  "message": "签到成功",
  "data": {
    "checkinId": 9001,
    "checkedAt": "2026-01-01 09:02:11",
    "checkedInCount": 39
  }
}
```

**错误**：重复签到返回 `code=1003`，`message="你已签到"`；课堂结束后返回 `1002`。

### 3.2 签到名单查询

```
GET /api/checkin/list?classroomId=12
```

```json
{
  "code": 0,
  "message": "success",
  "data": [
    { "studentId": 101, "studentNo": "2023001", "realName": "张*明", "checkedAt": "2026-01-01 09:02:11" }
  ]
}
```

> 大屏端展示需脱敏（`张*明`），教师端可请求 `?mask=false` 查看全名。

### 3.3 关闭签到窗口

```
PUT /api/checkin/{classroomId}/close
```

## 5. 题目与作答

### 5.1 发布题目

```
POST /api/exercise/publish
Authorization: Bearer <teacherToken>
```

```json
{
  "classroomId": 12,
  "type": "single",
  "stem": "下列哪个不是 Spring Boot 的启动方式？",
  "options": [
    { "key": "A", "text": "java -jar" },
    { "key": "B", "text": "mvn spring-boot:run" },
    { "key": "C", "text": "docker run" },
    { "key": "D", "text": "IDE 直接运行" }
  ],
  "answer": "C",
  "durationSeconds": 60
}
```

| 字段 | 说明 |
| :--- | :--- |
| type | `single` 单选 / `multiple` 多选 |
| answer | 单选为 `"C"`；多选为 `"A,C"` |
| durationSeconds | 答题倒计时，0 表示不限时 |

**响应**：返回 `exerciseId` 与 `publishedAt`。

### 5.2 学生提交答案

```
POST /api/exercise/{exerciseId}/answer
Authorization: Bearer <studentToken>
```

```json
{
  "content": "C"
}
```

```json
{
  "code": 0,
  "message": "提交成功",
  "data": { "answerId": 5001, "isCorrect": true, "submittedAt": "2026-01-01 09:10:02" }
}
```

**错误**：重复提交 `code=2001`；题目已截止 `code=2002`。

### 5.3 答题统计（大屏）

```
GET /api/exercise/{exerciseId}/statistics
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "totalStudents": 39,
    "submittedCount": 36,
    "correctCount": 30,
    "correctRate": 0.833,
    "optionDistribution": { "A": 3, "B": 2, "C": 30, "D": 1 }
  }
}
```

## 6. 抢答

### 6.1 发起抢答

```
POST /api/race/start
Authorization: Bearer <teacherToken>
```

```json
{
  "classroomId": 12,
  "exerciseId": 33,
  "durationSeconds": 10
}
```

**响应**：`{"raceId": 77, "startAt": "2026-01-01 09:20:00", "endAt": "2026-01-01 09:20:10"}`

### 6.2 学生抢答

```
POST /api/race/{raceId}/grab
Authorization: Bearer <studentToken>
```

```json
{ "studentId": 101 }
```

```json
{
  "code": 0,
  "message": "抢答成功",
  "data": {
    "isFirst": true,
    "rank": 1,
    "racedAt": "2026-01-01 09:20:03.245"
  }
}
```

**规则**：`isFirst` 由服务端 `raced_at`（数据库 `CURRENT_TIMESTAMP(3)`）判定，**严禁使用客户端时间**；同一学生同一题只计一次。

### 6.3 抢答排名

```
GET /api/race/{raceId}/ranking
```

```json
{
  "code": 0,
  "message": "success",
  "data": [
    { "rank": 1, "studentId": 101, "realName": "张*明", "racedAt": "2026-01-01 09:20:03.245" }
  ]
}
```

## 7. 数据看板（P1）

| 接口 | 说明 | 关键返回字段 |
| :--- | :--- | :--- |
| `GET /api/dashboard/checkin?classroomId=` | 签到统计 | expected, actual, rate, timeline[] |
| `GET /api/dashboard/accuracy?classroomId=` | 正确率统计 | averageRate, perExercise[]{id, rate} |
| `GET /api/dashboard/ranking?classroomId=&type=answer\|race\|active` | 排行榜 | list[]{rank, name, score} |
| `GET /api/dashboard/report?classroomId=&studentId=` | 学情报告 | student{...}, history[]{...} |
| `GET /api/export/checkin?classroomId=` | 导出签到 Excel | 文件流 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |

> 以上为 P1 占位契约，第 5 周落地时在本文件补全字段与示例，未补全前前端不得依赖。

## 8. WebSocket 消息契约（M4 维护）

| 项 | 值 |
| :--- | :--- |
| 端点 | `ws://localhost:8080/ws` |
| 订阅前缀 | `/topic/classroom/{classroomId}` |
| 发送前缀 | `/app/classroom/{classroomId}` |

**统一消息体**

```json
{
  "type": "CHECKIN",
  "timestamp": 1735689600000,
  "payload": {}
}
```

| type | 触发时机 | payload 关键字段 |
| :--- | :--- | :--- |
| `CHECKIN` | 学生签到成功 | studentId, realName（脱敏）, checkedInCount |
| `EXERCISE_PUBLISHED` | 教师发布题目 | exerciseId, type, stem, options, durationSeconds |
| `ANSWER_SUBMITTED` | 学生交卷 | exerciseId, submittedCount, totalStudents |
| `RACE_STARTED` | 抢答开始 | raceId, endAt |
| `RACE_FIRST` | 首个抢答 | studentId, realName, racedAt |
| `DANMU` | 弹幕（P1） | studentId, content |
| `CLASS_CLOSED` | 课堂结束 | classroomId |

## 9. 变更流程

1. 提出方修改本文件 → 提 PR（`docs/04-接口契约模板.md`）；
2. PM 审核字段命名、错误码、兼容性（**新增字段允许，删除/改名不允许**）；
3. 合并后在群内 @ 相关前端/后端负责人；
4. 后端同步改 Controller DTO，前端同步改 `services/*.ts`；
5. 版本记录追加一行。
